Amazon Web Services (AWS) offers several services that begin with "Cloud." Here's a categorized list with brief descriptions:



- **AWS CloudFormation**: Enables modeling and setting up AWS resources using infrastructure as code, allowing for automated and secure management of resources. 
    

    
- **AWS CloudWatch**: Monitors and provides observability of AWS resources and applications, offering data and actionable insights to ensure smooth operation.
    

**2. Networking & Content Delivery**

- **AWS CloudFront**: A fast content delivery network (CDN) service that securely delivers data, videos, applications, and APIs to customers globally with low latency.

**3. Application Integration**

- **AWS CloudSearch**: Manages and scales a search solution for a website or application, allowing for the addition of search capabilities without managing the underlying infrastructure.

**4. Security, Identity, & Compliance**

- **AWS CloudHSM**: Offers hardware-based key storage for regulatory compliance requirements, enabling secure key management using dedicated hardware security modules.

These services cater to various aspects of cloud computing, from infrastructure management and monitoring to security and content delivery.
