# Table of Contents — System Design Books

All books live in `Architecture/`.

## Priority

Read these first (previously in `Architecture/_Priority/`).

#todo/project/priority/High
- [ ] **Designing Data-Intensive Applications** — Kleppmann. Storage, replication, partitioning, transactions, batch/stream processing; the core book for distributed data systems.
- [ ] **Software Architecture: The Hard Parts** — Modern trade-off analysis for distributed architectures: service granularity, data decomposition, sagas, contracts.
- [ ] **Domain-Driven Design: Tackling Complexity in the Heart of Software** — Evans' original DDD book: ubiquitous language, bounded contexts, aggregates.
- [ ] **Cloud Application Architecture Patterns** — Patterns for building scalable, resilient cloud-native applications.
- [ ] **Clean Architecture** — Robert C. Martin. Dependency rule, boundaries, and structuring software around business rules.
- [ ] **Clean Code** — Robert C. Martin. Practical guide to writing readable, maintainable code.
- [ ] **Design Patterns: Elements of Reusable Object-Oriented Software** — The Gang of Four catalogue of 23 classic patterns.
- [ ] **Head First Design Patterns** — Visual, beginner-friendly walkthrough of the same core patterns.
- [ ] **Refactoring: Improving the Design of Existing Code** — Fowler. Catalogue of refactorings and code smells.
